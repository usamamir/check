# Uzi Mir — Portfolio

State-of-the-art personal portfolio for **Uzi Mir**, Amazon Master & E-commerce Strategist.

## Preview locally

```bash
cd portfolio
npm install
npm run dev
```

Production build:

```bash
cd portfolio
npm run build
npm run preview
```

## Stack

- Vite + React + TypeScript
- Lenis smooth scroll
- Custom editorial design system (Syne / Fraunces / JetBrains Mono)

## Deploy

GitHub Pages workflow deploys `portfolio/dist` on push. Live URL after Pages is enabled:

`https://usamamir.github.io/check/`
