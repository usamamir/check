# Repwise

Original strength training helper — **no login**.

1. Tap a **circular equipment** photo (barbell, dumbbell, cable, machine, bodyweight, kettlebell, or band)
2. Tap a muscle on the **front/back anatomy chart**
3. Watch demos for **that muscle and that equipment** — click another exercise to switch the video

## Windows install

https://github.com/usamamir/check/raw/cursor/repwise-workout-app-a8b2/downloads/Repwise-Setup.exe

1. Double-click `Repwise-Setup.exe`
2. If SmartScreen appears: **More info → Run anyway**

## Web

```bash
npm install
npm run dev
```
