# Jettribe Shopify theme

The uploadable theme is `jettribe-shopify-theme.zip`. Source files are in `jettribe-shopify/`. Upload steps and the payment setup are in `jettribe-shopify/UPLOAD.md`.

`jettribe-full-upload.zip` contains the theme zip, `jettribe-products.csv`, and a `category-links` folder. Import the product CSV first with overwrite unchecked. Then import `01` through `20` in that folder with overwrite checked. Those files include each product’s existing size options so Shopify can update products that already have variants, and they add one jettribe.com category per import. The same files are also in `jettribe-category-links.zip`. The clickable preview in `preview/` uses the same catalog.
