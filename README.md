# Jettribe Shopify theme

The uploadable theme is `jettribe-shopify-theme.zip`. Source files are in `jettribe-shopify/`. Upload steps and the payment setup are in `jettribe-shopify/UPLOAD.md`.

`jettribe-catalog.csv` is the product import (titles, prices, photos, descriptions, sizes, and name-plate fields). `jettribe-collections.csv` maps each product to its Jettribe collection. The clickable preview in `preview/` uses the same catalog, including collection filters and product options.
