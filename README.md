# Jettribe Shopify theme

The uploadable theme is `jettribe-shopify-theme.zip`. Source files are in `jettribe-shopify/`. Upload steps and the payment setup are in `jettribe-shopify/UPLOAD.md`.

`jettribe-full-upload.zip` contains the theme zip and `jettribe-products.csv`. Import that CSV in **Products → Import**. It has all 539 products, prices, photos, descriptions, sizes, and each product’s main collection. `jettribe-collections.csv` maps products to every category. The clickable preview in `preview/` uses the same catalog.
