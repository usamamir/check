# Jettribe Shopify theme

The uploadable theme is `jettribe-shopify-theme.zip`. Source files are in `jettribe-shopify/`. Upload steps and the payment setup are in `jettribe-shopify/UPLOAD.md`.

`jettribe-full-upload.zip` contains the theme zip, `jettribe-products.csv`, and a `category-links` folder. Import the product CSV first with overwrite unchecked. Then import `01` through `20` in that folder with overwrite checked. Shopify accepts one category per import, and each file adds the next jettribe.com category. The same files are also in `jettribe-category-links.zip`. The clickable preview in `preview/` uses the same catalog.
