# Repwise

Original strength training helper — **no login**.

1. Choose the equipment you have  
2. Tap muscles on the musculature anatomy chart (front + back)  
3. Browse **15+ exercises per muscle** with in-app YouTube demos and guidelines  
4. Click any exercise (or use Prev/Next) to switch the video  

## Windows install

https://github.com/usamamir/check/raw/cursor/repwise-workout-app-a8b2/downloads/Repwise-Setup.exe

1. Double-click `Repwise-Setup.exe`  
2. If SmartScreen appears: **More info → Run anyway**  
3. Pick equipment → tap a muscle on the chart → click exercises to change the video

## Web

```bash
npm install
npm run dev
```
