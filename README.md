# Repwise

Original strength training helper — **no login**.

1. Choose the equipment you have  
2. Tap muscles on a body map  
3. Get matching exercises with in-app YouTube demos  

## Windows install

https://github.com/usamamir/check/raw/cursor/repwise-workout-app-a8b2/downloads/Repwise-Setup.exe

1. Double-click `Repwise-Setup.exe`  
2. If SmartScreen appears: **More info → Run anyway**  
3. Pick equipment → tap muscles → press **Play demo**

## Web

```bash
npm install
npm run dev
```
