# Jettribe Shopify theme

The uploadable theme is `jettribe-shopify-theme.zip`. Source files are in `jettribe-shopify/`. Upload steps and the payment setup are in `jettribe-shopify/UPLOAD.md`.

`jettribe-full-upload.zip` contains the theme zip and `jettribe-products.csv`. Import that one CSV in Products → Import with overwrite checked. It has all 541 products, photos, prices, size options, all 159 category tags, and the plate and sock add-ons. Do not open it in Excel, and do not import the older category sheets. The clickable preview in `preview/` uses the same catalog.
