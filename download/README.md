## Install / run on Windows

1. Open the link **in Chrome, Edge, or Firefox** (not inside the Cursor app)
2. Save `Streakly-Setup.exe` to your Desktop or Downloads folder
3. Double-click `Streakly-Setup.exe`
4. If Windows SmartScreen appears:
   - Click **More info**
   - Click **Run anyway**
5. Wait a few seconds the first time — then Streakly opens

**Requirements:** Windows 10 or 11, 64-bit

No separate installer wizard is required — this is a portable app. Double-click to run.
